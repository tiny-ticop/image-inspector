# 機台画像 コマ送りビューア

`../data/raw/機台/delay/角度/*.jpg` の原画像を、コマ送りや自動再生で確認し、周期間の変動を数値化するローカル専用ツールです。JPEG形式（.jpg / .jpeg）に対応します。元画像・マスク・既存の確認結果は変更しません。変動解析には既存の仮想環境に導入済みのNumPy・OpenCVを使います。別環境では `requirements.txt` の依存を導入してください。

## 入力パスと起動

リポジトリ直下の PowerShell で実行します。初回セットアップはルートの README.md を参照してください。

入力・保存先は `--config config.local.json`、または `--raw-dir` / `--output-dir` で指定できます。相対パスは設定ファイル内ではそのファイルの場所、CLIでは現在の作業フォルダが基準です。人工サンプルは `--config examples/demo/config.json` で起動できます。引数なしの既定値は従来と同じです。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\frame_viewer\start.ps1
```

ブラウザで http://127.0.0.1:8769/ を開きます。終了は起動した端末で Ctrl+C。ポートが使用中の場合は、末尾に `--port 8770` を追加し、表示されたURLを開いてください。起動スクリプトはASCII文字のみで、Windows PowerShellでも実行できます。

既存の `../.venv/Scripts/python.exe` を使用します。HTMLファイルを直接開かず、上記サーバー経由で利用してください。画像を追加・削除した際はサーバーを再起動して一覧を更新します。

## 操作

- 表示する機台にチェックを付けます。複数選択すると2列で並び、狭い画面では1列になります。「すべて表示」で全5機台を表示できます。
- 各表示枠で「角度指定」または「機台内の全角度」と角度を選びます。機台ごとに異なる角度・再生範囲を指定できます。
- 角度指定では選択角度内をファイル名順、全角度では角度の数値順→各角度内のファイル名順に表示します。
- 「まとめて再生」「まとめて一時停止」で表示中の全機台を操作します。前後1枚、先頭／末尾も一括操作です。位置スライダーは各機台に用意しています。
- 速度は全機台共通で1・2・5・10コマ／秒。初期値は2コマ／秒で、繰り返し再生は有効です。一時停止するまで各機台は自身の末尾から先頭へ戻って再生を続けます。チェックを外した場合のみ末尾で停止します。
- 左右キーでまとめてコマ送り、Spaceでまとめて再生／停止。入力欄やセレクトではその要素の標準キー操作を優先し、ボタン上のSpaceはそのボタンを操作します。
- 全体表示・原寸・200%拡大に対応し、拡大時はスクロールできます。
- 機台の追加・削除や範囲・角度・位置を変更すると全機台を一時停止します。範囲・角度を変更した枠だけ先頭へ戻り、他の枠の位置は保持します。新しい機台は先頭を表示します。タブが非表示になった場合も一時停止します。
- 前後2枚だけ先読みします。読み込みが遅い場合も順番を維持し、表示間隔を延ばします。読み込み失敗・30秒のタイムアウト時は停止してファイル名を表示します。

撮影間隔を再現した動画ではありません。同じ角度内の画像は別周期の観測です。角度をまたぐ再生も同一周期の連続撮影を意味しません。複数機台は同じ速度設定でそれぞれ再生し、枚数と読み込み時間が異なるため画像位置や撮影時刻は同期しません。画像エラーがあった場合は全機台を停止し、該当枠にファイル名を表示します。

## 変動解析の操作

サーバー機能が増えたため、旧版からの更新時は端末でCtrl+Cで停止し、起動し直してからブラウザでCtrl+F5を押してください。

1. 各機台枠の「変動解析・ROI」を開きます。「この角度を解析」で現在表示中の角度に属する全画像を計算します。保存済み結果があれば再利用します。
2. 表示を「分類」「標準偏差」「MAD」「95–5%幅」「明暗成分」「構造成分」「出現割合」「方向のばらつき」「この画像の差分」に切り替えます。集約表示はその角度の全画像の統計、この画像の差分は再生中の1枚の値です。
3. 「除外範囲」を選ぶと、評価しない上端・外周・補正境界を赤で表示します。
4. 原画像または重畳画像上を左ドラッグし、矩形ROIを指定します。ROIの数値、分類面積比、画像ごとの明暗／構造変化量グラフが表示されます。グラフをクリックすると該当画像へ移動します。ROIのCSV・JSON出力も可能です。
5. 画面上部の「変動解析の条件・まとめて計算」では、表示中の角度の一括計算、選択機台の全角度の事前計算、各閾値・除外幅の変更ができます。変更後は「未解析」となり、解析要求後に新しい条件の結果を作ります。再生範囲の全角度を混ぜて統計を作ることはありません。
6. 平行移動補正を有効にすると、補正後のグレースケール画像とその座標の特徴・ROIを表示します。補正は別の解析結果として保存します。失敗した角度は警告し、原画像側の結果は保持します。

計算は1角度ずつバックグラウンドで行い、通常の画像再生は継続できます。結果のダウンロードには「計算条件JSON」「特徴量NPZ」を使えます。

### 特徴と分類の定義

基準は同一機台・同一角度の全画像の画素別中央値です。正常・不在のみの参照ではなく、評価画像自身も含む記述的統計です。

- std：輝度の母標準偏差。mad：中央値からの絶対差の中央値（1.4826倍はしない）。spread：95–5パーセンタイル幅。
- low：基準との差をGaussian sigma=12で平滑化した広域明暗成分の絶対値を9×9平均。
- high：差分から平滑成分を引いた細部の構造成分の絶対値を9×9平均。
- low_mean / high_mean：上記の全画像平均。
- low_frequency / high_frequency：上記が差分閾値10を超えた枚数／有効画像数。振動周波数ではありません。
- orientation：structure tensorによる方向の円統計の分散指標（0〜1）。方向の180°同値を扱い、coherence>=0.2、勾配エネルギー>=4の画像が半数以上必要です。条件を満たさない画素は透明・ROI平均から除外します。初版の分類条件には使いません。

原寸処理し、除外範囲を混ぜない重み付き平滑化・小領域平均を使います。上端60px・外周8pxは初期設定です。位置補正は安定構造の連続領域を使い、位相相関による初期値とECCの平行移動補正を比較します。参照との差分を増やす補正は採用しません。移動20px超・品質不足・収束失敗は補正解析の失敗として報告します。補正の成否だけで正確な位置合わせを保証しません。

分類値は0=評価対象外、1=変動が小さい、2=広域明暗変動主体、3=少数画像の構造変化、4=中程度の出現割合の構造変化、5=多くの画像にある構造変化、6=混合・判別保留です。

全画像でlow/highが閾値以下なら1です。変化があり、平均lowがlow+highの2/3以上なら2、平均highが2/3以上ならhighの出現割合が20%以下で3、20%超〜50%未満で4、50%以上で5です。それ以外は6です。閾値や割合境界は画面から変更できます。明暗成分を照明、構造成分を物体の移動と断定しません。

表示スケールは共通で、std/MAD/明暗・構造は0〜30、分位点幅は0〜60輝度値、割合・方向指標は0〜1です。上限以上は飽和表示し、元数値はNPZに保持します。色は画像ごとに自動調整しません。

### 保存と再計算

`outputs/variation/<解析ID>/` に次を保存します。

- `result.json`：入力画像SHA-256、設定、変換・品質、分類面積、画像ごとの数値、時間、追跡メモリ、依存バージョン。
- `maps.npz`：原寸の特徴・有効範囲・分類・中央値。方向指標は `orientation_valid` と併用します。
- `frames.npy`：その解析座標のグレースケール画像群。補正後ROIの再集計に使用します。元画像は変更しません。
- `series.csv` / `transforms.csv`：画像ごとの変化量、補正の推定結果。
- `previews/`：表示要求時に生成するPNG。
- `roi/`：指定矩形の条件・集計JSONと画像ごとの数値CSV。

解析IDは画像内容・設定・手法バージョンのハッシュです。サーバー再起動時には元画像と一致する保存済み結果を読み込みます。画像変更時は再起動して一覧を更新し、解析を再要求してください。元マスク・種別マスクはこの解析に使用しません。

一括計算は `.\.venv\Scripts\python.exe .\frame_viewer\analyze_all.py` でも実行できます。`--aligned --representatives` で各機台の代表1角度の位置補正結果を作れます。`verify_variation.py` は全46角度の保存結果と入力ハッシュを検証します。


### 解析API

- `POST /api/variation/submit`：`groups: [{machine, angle}], settings: {...}` を渡し、解析IDと状態を返します。
- `GET /api/variation/jobs`：全解析の状態。`?id=...` で1件の状態・完了結果を取得します。
- `GET /api/variation/image?id=...&feature=...&frame=...`：集約／画像別PNGまたは補正画像。
- `POST /api/variation/roi`：`{id, rectangle: [x0,y0,x1,y1]}`。半開区間の原寸座標で集計し、ROI出力IDを返します。
- `GET /api/variation/download`：許可された解析ファイル・ROI CSV/JSONを取得します。

解析は3枚以上必要です。読み込み失敗や寸法不一致はその角度の失敗として表示します。変動クラスの正解注釈はないため、数値と元画像を照合する探索として利用してください。

## 全角度の教師なしパターン発見

旧版から更新した場合はサーバーをCtrl+Cで止めて起動し直し、ブラウザでCtrl+F5を押してください。現在、初期設定で全5機台の計算結果を保存しています。

1. 各機台枠の「全角度の教師なしパターン」を開きます。「この機台で発見」で機台内の全角度を処理します。上部の同名設定からは、選択中機台をまとめて要求できます。
2. 「クラスタを重畳」を有効にすると、固定場所の変動パターンを色分けします。灰色は未分類です。既存の角度別変動マップとは切り替えて表示します。
3. 群のボタンでその群を強調し、代表領域を5件表示します。白枠が解析した小領域で、周囲も含めた画像を表示します。クリックすると対応領域と角度グラフが表示されます。
4. 散布図は同位相内の特徴MAD平均と、位相間の代表輝度の標準偏差をlog表示します。これは多次元特徴の一部を示す図です。点のクリックで領域を選択できます。
5. 重畳画像上を左ドラッグして任意の矩形ROIを指定できます。ROI内に中心がある小領域を集計します。画素精度の領域抽出ではありません。
6. 角度グラフは実角度を横軸にし、代表輝度±周期間MAD、または明暗・構造の差分量を切り替えられます。点をクリックするとその角度へ移動します。「角度別中央値」では別周期の1枚と異なる集約画像で状態を確認できます。欠けた角度を推定せず、末尾と先頭も接続しません。
7. 各群に名前・メモを付けて「メモ保存」を押せます。注記は教師として学習に戻さず、クラスタ結果を変更しません。
8. 最小群サイズ20・40・80と小領域幅8・16・32pxを変更して比較できます。設定変更時は古い表示を解除し、必要なら再計算します。群番号・色は同じ機台・同じ解析結果の中だけで対応します。

### 計算内容と限界

- 原画像の共通座標で、16×16pxを8px間隔で配置します。除外幅・差分閾値等は既存の変動解析設定を引き継ぎ、角度別位置補正は使いません。角度間で寸法が異なる場合は失敗を表示します。
- 各画像・小領域の輝度平均、コントラスト、勾配、方向のcos(2θ)/sin(2θ)と有効率、明暗・構造・絶対差分・RMS差分を計算します。差分参照は各角度の全画像中央値です。
- 同位相内ブロックは角度ごとのMAD・分位点幅・平均差分・変化割合など、位相間ブロックは中心を引いた代表値の角度曲線・角度差で割った差分・変化幅、関係ブロックは位相間／位相内の比や変動の集中度です。各角度を等しく重み付けします。
- 方向が求まらない値は欠測として中央値補完し、欠測指標を加えます。RobustScalerで正規化し、特徴群を次元数の平方根で調整して寄与を均等化します。極端な正規化値は±20で制限します。
- PCAは95%の分散保持を目標に最大20次元まで使用します。上限のため実際の保持率は今回約71〜78%でした。画面とJSONに実値を表示します。
- HDBSCANは群数を固定せず、初期の最小群サイズ40・近傍数10で計算します。単一群を許可し、均一な特徴は1群、群が見つからない場合は未分類を返します。緯糸・経糸の手動指定や分類マスクは教師・入力に使いません。
- 背景の位置ずれを参考診断しますが、推定シフトを用いて角度に伴う変化を消す位置合わせはしません。診断で警告がないことは、位置ずれが完全にない証明ではありません。

安定性はseed=42、各角度の画像特徴を復元抽出して10回再計算します。ラベル番号の入れ替えを考慮したARI、両方で採用された割合、群ごとの対応付けJaccard、群数・未分類率の範囲を表示します。すべて未分類の場合のARIは対象外です。群への所属強度も、正解確率ではありません。**再抽出時の差分参照中央値は固定しており、参照画像の推定不確かさを含む完全なブートストラップではありません。**

クラスタは固定位置の似た変動特徴の集まりで、物体追跡や物理原因の識別ではありません。重なる小領域は独立観測ではなく、表示は中心に対応する8pxセルです。各機台で約8〜10°の限られた範囲を解析し、全360°へ一般化しません。角度別の収録時刻の違いによる状態差も混ざり得ます。


### 保存・API・再実行

`outputs/pattern_discovery/<解析ID>/` に、`result.json`（設定・角度一覧・参照解析ID・群・安定性・注意点）、`features.npz`（特徴群・PCA後の特徴・所属・曲線・中央値画像）、`observations.npz`（画像ごとの小領域特徴）、`model.joblib`、`points.json`、`regions.csv`、`previews/`、`notes.json`（保存操作後）を保持します。初期5機台の結果は約424MBです。元画像や既存の指定結果は保持します。

CLIは `.\.venv\Scripts\python.exe .\frame_viewer\discover_all.py`。`--machine demo_A`、`--min-cluster-size 80` で対象や条件を指定できます。`verify_discovery.py` は全5機台の初期結果を検証し、`summary.csv`、`verification.json`、原画像・重畳の `overview.jpg` を生成します。

- `POST /api/discovery/submit`：`machines`、`settings`、`variation_settings` で計算要求。
- `GET /api/discovery/jobs`：進捗・結果。既存の角度別解析と同じ待ち行列で処理します。
- `GET /api/discovery/points`、`image`、`thumbnail`：散布図・クラスタ画像・中央値・代表領域。
- `POST /api/discovery/region`：`{id,index}` または `{id,rectangle:[x0,y0,x1,y1]}` で角度別曲線と構成群を取得。
- `GET/POST /api/discovery/notes`：表示上の群名・メモを保持。
- `GET /api/discovery/download`：設定JSON、特徴NPZ、領域CSV等の出力。

## テスト手順

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s .\frame_viewer\tests -p "test_*.py"
node .\frame_viewer\tests\test_player.cjs
```

Pythonテストは人工サンプルの機台・角度・画像一覧、角度・画像の並び順、空フォルダ、HTTP配信、読み込み失敗、未許可パス、ポート競合を確認します。Nodeテストは再生順、角度境界、速度、ループ、停止、位置移動、空の再生範囲、非同期読み込みの逆転、読み込みエラーを確認します。Nodeは検証時だけ必要で、ツールの利用には不要です。

ヘッドレスChromeで複数機台の画像表示、機台別の全角度設定、初期ループ有効、末尾から先頭への一括再生、全機台一時停止、選択解除を確認済みです。実ブラウザテストはサーバー起動中に `node .\frame_viewer\tests\test_browser.cjs` で実行できます（Node 22以降とChromeが必要）。初期表示を止めていたブラウザタイマーの呼び出しについても回帰テストがあります。キーボード・拡大スクロールの目視操作確認は未実施です。

変動解析のブラウザテストは `$env:VARIATION_TEST='1'` を設定してから同じテストを実行します。事前に人工サンプルの原画像・補正後の代表角度を計算してください。分類重畳、マウスROI、グラフ移動、設定の切り替え、補正座標の画像別差分を検証します。計算条件・検証結果は出力フォルダに保存します。

教師なし発見のブラウザテストは `$env:DISCOVERY_TEST='1'` で有効にできます。事前に人工サンプルの初期条件の解析結果が必要です。代表画像、群の強調、角度グラフ、中央値表示、矩形ROI、古い結果の解除を確認します。解析条件・安定性・解釈上の制約は各結果のJSONに記録します。
