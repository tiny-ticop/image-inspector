# 糸領域マスク確認ツール

`../data/raw` と `../data/masks` の同じ相対パス・同じファイル名（拡張子を除く）を対応付けます。元データは変更しません。マスク値1をオレンジで表示します。緯糸と経糸の種別は区別できないマスク形式です。

## 起動

リポジトリ直下で PowerShell を開き、実行します。初回のセットアップはルートの README.md を参照してください。

入力・保存先は `--config config.local.json`、または `--raw-dir` / `--mask-dir` / `--output-dir` で指定できます。人工サンプルは `--config examples/demo/config.json` です。設定内の相対パスは設定ファイルの場所を基準に解決します。引数なしの既定値は従来互換です。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\mask_review_tool\start.ps1
```

起動時に全画像の対応・寸法・マスク値を点検します。表示された `http://127.0.0.1:8765/` をブラウザで開いてください。終了は起動した端末で Ctrl+C。ポート変更は `start.ps1 --port 8766`。

## 環境の再構築

Python 3.12 で作成済みの `../.venv` を使います。別PCでは LH-analysis 内で以下を実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\mask_review_tool\requirements.txt
```

## 確認方法

- 機台・機台角度を選び、左右矢印または前へ／次へで画像を切り替えます。
- 原画像と重畳画像を横並びで照合します。濃さ変更・マスク表示切り替えで見落としや部品の混入を確認します。
- 原寸・200%・400%に拡大してスクロールすると左右が連動します。
- 確認結果とメモは編集後に自動保存します。保存ボタンでも保存できます。保存失敗時は画像送りを止め、画面にエラーを表示します。
- 「空マスク・データ不備のみ」で確認が必要なデータを抽出できます。空マスクが誤りかどうかは元画像と照合してください。
- 問題なしは糸領域の目視確認結果です。未確認・判断保留を承認済みGTに含めないでください。

## 矩形に接触する糸マスク全体に種別を付ける

1. 「選択する種別」で緯糸（青）、経糸（緑）、重なり（紫）、判別不能（黄）を選びます。
2. 左の原画像で左ボタンを押しながらドラッグし、離すと登録します。開始ボタン・確定ボタンは不要です。
3. 矩形内のマスク値1の画素を起点に、8近傍（縦・横・斜め）でつながる領域全体に種別を付けます。矩形外まで延長します。離れたマスク領域は選択しません。右の重畳画像に種別色を表示します。
4. 領域ごとの説明を記入できます。選択と説明は自動保存します。取り消す場合は領域の削除ボタンを使います。ドラッグ中の取消は Esc です。
5. 拡大表示でも原画像座標で保存されます。「種別マスクPNG出力」で表示中画像の種別マスクを出力できます。

マスク上で緯糸と経糸がつながっている場合、それらは一つの領域として選択されます。矩形を小さくしても分離できません。その場合は重なり・判別不能として残すか、後でマスクを分離してください。同じ画素に緯糸・経糸を指定した場合は重なりとなります。判別不能が最優先です。誤った指定は削除して付け直してください。

種別PNGは原画像と同じ寸法のグレースケール画像で、0=未指定または元マスク外、1=経糸、2=緯糸、3=重なり、4=判別不能です。0から未指定の糸と背景を区別するには元マスクも併用してください。重なり・判別不能・未指定の糸は種別評価から除外できます。

選択は `outputs/reviews.json` の `regions` に `selection: mask_connected` として矩形座標・種別・説明を保存します。種別PNGはこの情報と元マスクから生成するため、元マスクを変更した際には再確認してください。以前の矩形指定も新しい連結領域ルールで表示・出力します。以前の多角形は参考囲みとして保持し、画素種別には自動変換しません。元画像・元マスク・以前の確認結果は保持します。

まず各機台の代表例を数枚指定してください。すべての糸を分類する必要はありません。

## 保存先のファイル

- `outputs/inventory.json`：起動時に再生成するデータ対応・点検結果。
- `outputs/reviews.json`：画像ごとの確認状態、メモ、更新日時（UTC）。サーバー再起動後も保持します。
- CSV / JSON 出力：未確認も含む全画像の確認結果をブラウザからダウンロードします。

画像・マスクが変更された場合はサーバーを再起動してください。同じパスの内容を差し替えた場合、以前の確認結果が残るので再確認してください。単独の index.html を直接開くのではなく、起動したローカルサーバーを使用します。同一PCで一人ずつ確認する用途です。

## 別データへの誤適用防止

`source_fingerprints.json` に原画像・マスクの内容ハッシュを保存します。同じ相対パスでも内容が変われば旧記録を隔離し、適用しません。移動・コピーしても内容と相対パスが同じなら結果を使えます。従来の `reviews.json` は初回移行時にバックアップし、現在のデータへ対応付けます。過去の画像との同一性は検証できないため、画面に通知します。
